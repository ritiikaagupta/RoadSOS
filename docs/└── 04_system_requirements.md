# System Requirements

## Functional Requirements

FR-01
System shall detect an emergency event.

FR-02
System shall generate an emergency packet.

FR-03
System shall calculate CRC.

FR-04
System shall perform LoRa modulation.

FR-05
System shall transmit the emergency message.

FR-06
Receiver shall synchronize with the incoming frame.

FR-07
Receiver shall demodulate the signal.

FR-08
Receiver shall validate CRC.

FR-09
Receiver shall generate an emergency alert.
